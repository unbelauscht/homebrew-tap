# unbelauscht's Homebrew Tap 🍺

Official Homebrew tap for [ineedspace](https://github.com/unbelauscht/ineedspace).

## Installation

```bash
brew install unbelauscht/tap/ineedspace
```

Or add the tap first:

```bash
brew tap unbelauscht/tap
brew install ineedspace
```
